# CSV 가져오기 · CSV 추출 · XLSX 추출

하위 프로젝트를 여러 건 한꺼번에 등록하거나, 등록된 내용을 파일로 받아 보는 방법입니다.

> [!TIP]
> **엑셀이나 구글 시트가 없어도 됩니다.** CSV 는 메모장으로 열고 고칠 수 있습니다.
> 5층처럼 오피스가 없는 PC 에서도 그대로 쓸 수 있습니다.

| 버튼 | 무엇을 하나 | 어디서 여나 |
|---|---|---|
| **CSV 업무 가져오기** | CSV 파일의 줄마다 하위 프로젝트를 만든다 | — |
| **CSV 추출** | 이 프로젝트의 하위 프로젝트를 CSV 로 받는다 | 메모장, 엑셀 |
| **XLSX 추출** | 같은 내용을 엑셀 파일로 받는다 (보고서·공유용) | 엑셀 |

세 버튼 모두 **프로젝트 탭 → 프로젝트 카드 아래 버튼 줄**에 있습니다.

---

## 1. 가장 쉬운 방법 — 내보낸 파일을 고쳐서 다시 넣기

1. 프로젝트 카드에서 **CSV 추출**을 눌러 파일을 받습니다.
2. 받은 파일을 **메모장**으로 엽니다. (파일 오른쪽 클릭 → 연결 프로그램 → 메모장)
3. 줄을 고치거나, 아래에 줄을 더합니다. 줄 하나가 하위 프로젝트 하나입니다.
4. 저장합니다.
5. 같은(또는 다른) 프로젝트 카드에서 **CSV 업무 가져오기** → **CSV 파일 선택**으로 넣습니다.
6. 미리보기에서 줄마다 **정상** 인지 확인하고 **N건 일괄 등록**을 누릅니다.

> [!IMPORTANT]
> 첫 줄의 **열 이름은 고치지 마세요.** 가져오기는 열 이름으로 칸을 찾습니다.
> 쓰지 않는 열은 비워 두거나 통째로 지워도 됩니다.

---

## 2. 처음부터 만들 때

창의 **양식 다운로드**로 빈 양식을 받거나, 메모장에 직접 씁니다.

```csv
기능명,평균소요시간(분),가중치,담당자,Lv
TST+RGR,120,5,홍길동,LV2
02_Diagnosis,90,3,"김철수, 이영희",LV3
27_Signal_Interface,,,,
```

| 열 | 필수 | 적는 법 |
|---|:---:|---|
| 기능명 | ✅ | 하위 프로젝트 이름이 됩니다. 비어 있으면 `하위 프로젝트` 열 값을 씁니다 |
| 평균소요시간(분) | | 숫자. 소수점도 됩니다 (`90.5`) |
| 가중치 | | 1~10 |
| 담당자 | | 이 프로젝트 **참여 인원**의 이름. 여럿이면 `"김철수, 이영희"` 처럼 큰따옴표로 묶습니다 |
| Lv | | `기초검증` · `LV1` · `LV2` · `BSW` · `LV3` · `LV4` |

- **기능명만 있으면 등록됩니다.** 위 예시의 마지막 줄처럼 나머지를 비워 두고 나중에 하위 프로젝트 수정에서 채워도 됩니다.
- 시작일·종료일은 CSV 에 넣지 않습니다. 가져오기 창의 **기본 시작일 · 기본 종료일**이 모든 줄에 들어갑니다.
- 값 안에 쉼표가 있으면 그 칸을 큰따옴표로 묶습니다.

---

## 3. 저장할 때 인코딩

메모장의 **다른 이름으로 저장 → 인코딩**에서 고릅니다.

| 인코딩 | 가져오기 |
|---|---|
| UTF-8 (요즘 메모장 기본값) | ✅ |
| UTF-8(BOM) | ✅ |
| ANSI (옛 메모장 기본값, 엑셀의 "CSV(쉼표로 분리)") | ✅ (2026-10-01 부터) |

예전에는 UTF-8 만 읽어서 엑셀이나 옛 메모장으로 저장한 파일은 한글이 깨져
"열을 찾지 못했습니다"가 떴습니다. 지금은 자동으로 알아봅니다.

---

## 4. 미리보기에서 빨간 줄이 나올 때

| 문구 | 뜻 | 고치는 법 |
|---|---|---|
| `다음 열을 찾지 못했습니다: 기능명 또는 하위 프로젝트` | 이름 열이 없음 | 첫 줄에 `기능명` 열을 넣습니다 |
| `담당자 없음: 홍길동` | 그 이름이 프로젝트 참여 인원에 없음 | 이름 오타를 고치거나, 프로젝트 수정에서 참여 인원에 넣습니다 |
| `동명이인 담당자: 김민준` | 같은 이름이 둘 이상 | 담당자 칸을 비우고 등록한 뒤 하위 프로젝트 수정에서 고릅니다 |
| `평균 소요 시간은 1분 이상의 숫자로 입력` | 숫자가 아닌 값 | 숫자만 남기거나 비웁니다 |
| `가중치는 1~10 사이 숫자로 입력` | 범위 밖 | 1~10 으로 고칩니다 |
| `Lv 값 오류: LV5` | 없는 레벨 | 위 표의 값 중 하나로 고칩니다 |

빨간 줄은 등록되지 않고, 정상인 줄만 등록됩니다.

---

## 5. CSV 추출과 XLSX 추출

- **CSV 추출**: 화면의 모든 칸(검증 상태·소요 시간·특이사항·사용자 지정 항목 등)이 들어갑니다.
  메모장으로 볼 수 있고, 고친 뒤 다시 가져올 수 있습니다.
- **XLSX 추출**: 같은 내용을 엑셀 형식으로 받습니다. 엑셀이 없는 PC 에서는 열 수 없고,
  **가져오기에는 쓸 수 없습니다.** 보고서로 만들거나 엑셀이 있는 사람에게 보낼 때 씁니다.

> [!NOTE]
> 내보낸 CSV 를 그대로 다시 가져오면 하위 프로젝트가 **새로** 만들어집니다.
> 기존 하위 프로젝트를 고치는 기능은 아닙니다. 고치려면 하위 프로젝트 수정을 쓰세요.
