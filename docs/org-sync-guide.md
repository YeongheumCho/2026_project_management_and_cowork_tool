# 인원 동기화 가이드

그룹웨어 조직도로 SureLog 사용자 목록을 맞추는 방법입니다. 한 번에 3~4분 걸립니다.

```mermaid
flowchart LR
    A["그룹웨어 로그인"] --> B["조직도 열기"]
    B --> C["F12 콘솔에<br/>스크립트 붙여넣기"]
    C --> D["CSV 내려받기"]
    D --> E["관리 > 인원 동기화<br/>파일 올리기"]
    E --> F["미리보기"]
    F --> G["반영하기"]
```

## 언제 하나

새 인원이 들어오거나 퇴사·조직 개편이 있을 때 합니다. 매일 돌려도 되고, 주 1회나 월 1회로 정해 두어도 됩니다.
같은 파일을 여러 번 올려도 이미 반영된 내용은 다시 바뀌지 않습니다.

## 순서

### 1. 그룹웨어에서 CSV 받기

1. 그룹웨어(`gw.suresofttech.com`)에 로그인합니다.
2. 화면 왼쪽 아래 **조직도**를 눌러 트리를 엽니다.
3. `F12`로 개발자 도구를 열고 **Console** 탭으로 갑니다.
4. SureLog **관리 > 인원 동기화 > 그룹웨어에서 CSV 받는 방법**에서 스크립트를 복사합니다.
5. 콘솔에 붙여넣고 `Enter`를 누릅니다.
6. 끝나면 `org_YYYYMMDD.csv`가 내려받아집니다. 100명 기준 20초쯤 걸립니다.

받을 범위는 스크립트 위의 **받을 센터** 칸으로 정합니다. 기본값은 `E-모빌리티센터`이고,
비우면 전사 전체를 받습니다.

> [!TIP]
> 콘솔에 붙여넣기가 막혀 있으면 `allow pasting` 을 입력하고 `Enter` 를 누른 뒤 다시 붙여넣으세요.
> 크롬이 처음 한 번 물어봅니다.

### 2. SureLog에 올리기

1. **관리 > 인원 동기화**로 갑니다.
2. 받은 CSV를 선택합니다. 읽은 인원 수가 표시됩니다.
3. **미리보기**를 누릅니다. 무엇이 바뀌는지만 보여주고 저장하지 않습니다.
4. 내용을 확인한 뒤 **반영하기**를 누릅니다.

미리보기에서 보게 되는 항목입니다.

| 항목 | 뜻 |
|---|---|
| 새로 추가 | 그룹웨어에 있고 SureLog에 없는 사람. 계정이 생깁니다 |
| 소속·직급 변경 | 실·팀·직급·연락처가 달라진 사람 |
| 비활성 처리 | 그룹웨어에 없는 사람. 퇴사자로 봅니다 |
| 다시 활성 | 껐다가 다시 목록에 나타난 사람 |
| 사번 보정 | 앞자리 0이 빠져 저장돼 있던 사번을 9자리로 맞춤 |
| 본인이라 건너뜀 | 동기화를 실행한 관리자 본인 계정 |

## 규칙

**사번이 기준입니다.** 이름이 같아도 사번이 다르면 다른 사람으로 봅니다. 9자리로 맞춰 비교하므로
앞자리 0이 빠진 값도 같은 사람으로 인식합니다.

> [!IMPORTANT]
> **퇴사자는 지우지 않고 비활성으로 돌립니다.**
> 계정을 지우면 그 사람이 담당했던 프로젝트와 수행 이력에서 담당자가 비어 버립니다.
> 비활성이면 새 업무 배정 후보에서는 빠지고 과거 기록은 그대로 남습니다.

**관리자도 퇴사하면 비활성됩니다.** 단 동기화를 실행한 본인 계정은 끄지 않습니다.
작업 도중 스스로 로그아웃되면 되돌릴 수 없기 때문입니다. 본인이 퇴사 대상이면 다른 관리자가 처리해야 합니다.

> [!NOTE]
> **권한과 비밀번호는 절대 바뀌지 않습니다.**
> 관리자로 지정해 둔 사람이 CSV 때문에 일반 사용자로 내려가는 일은 없습니다.
> 새로 만들어지는 계정의 초기 비밀번호는 `12345678` 입니다.

**비활성 범위를 센터로 제한할 수 있습니다.** 파일에 한 센터만 들어 있으면 자동으로 그 센터가 선택됩니다.
다른 센터 인원이 파일에 없다는 이유로 꺼지는 것을 막아 줍니다.

## CSV 형식

직접 만들거나 엑셀에서 편집해도 됩니다.

```
idnum,name,center,office,team,position,email,phone
190916003,진보라,E-모빌리티센터,Automotive시스템실,Automotive검증1팀,수석연구원,brjin@suresofttech.com,010-9281-5263
```

`idnum`과 `name`만 필수입니다. 나머지는 비워도 되고, 모르는 열은 무시합니다.
파일은 UTF-8로 저장하세요. 엑셀에서 저장할 때는 "CSV UTF-8(쉼표로 분리)"를 고르면 됩니다.

## 되돌리기

반영 전 상태는 `backups/` 아래에 남겨 둡니다. 되돌리려면 해당 SQL을 넣으면 됩니다.

```bash
docker compose exec -T db psql -U $POSTGRES_USER -d $POSTGRES_DB < backups/users_before_sync_260915.sql
```

큰 변경 전에는 백업을 먼저 뜨는 편이 안전합니다.

```bash
docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -t users --data-only --column-inserts' > backups/users_$(date +%y%m%d).sql
```

## 잘 안 될 때

<details>
<summary><strong><b>"조직도 트리를 찾지 못했습니다"</b></strong></summary>

조직도를 열지 않은 상태입니다. 화면 왼쪽 아래 조직도를 먼저 누른 뒤 다시 실행하세요.

</details>

<details>
<summary><strong><b>인원이 0명으로 나옴</b></strong></summary>

센터 이름이 조직도 표기와 다릅니다. 트리에 보이는 이름 그대로 넣으세요.

</details>

<details>
<summary><strong><b>중간에 멈춘 것 같음</b></strong></summary>

콘솔에 20명마다 진행 상황이 찍힙니다. 탭을 다른 창으로 가려도 동작하지만,
그룹웨어 탭을 보이는 상태로 두면 조금 더 빠릅니다.

</details>

<details>
<summary><strong><b>사번이 빈 사람이 있음</b></strong></summary>

그룹웨어 카드에 사번이 없는 계정입니다. 그런 줄은 CSV에서 제외됩니다.
필요하면 관리 > 사용자 권한 관리에서 직접 추가하세요.

</details>
